# Keys and mouse

Every shortcut in one place. On the Mac use Cmd; on Windows and Linux, Ctrl.

| | |
|---|---|
| Space | Play / stop. Stop twice to return to the start. Works from anywhere in Lathe: the mixer, a plug-in's window, a dialog without a text box. While you type in a text box, Space types a space. |
| R | Record |
| C | Metronome |
| L | Loop on/off (drag in the top strip of the ruler to set the loop) |
| F | Follow Playhead on/off. On, the arrangement scrolls to keep the playhead in view while playing; off, you can scroll anywhere while it plays. Also the transport's **Follow** button and View > Follow Playhead; Lathe remembers it. |
| Tab | Arrangement / mixer |
| Cmd/Ctrl+S, +Shift+S | Save / Save As. These and the other File shortcuts (Cmd/Ctrl+O open, Cmd/Ctrl+N new, Cmd/Ctrl+Shift+E export audio) also work with a plug-in's window in front; the plug-in keeps the rest of its keys (its own undo and copy, say). |
| Cmd/Ctrl+B | Plug-in browser |
| Cmd/Ctrl+G, +Shift+G | Group the selected tracks / ungroup |
| Cmd/Ctrl+T, +Shift+T, +Alt+T | Add audio / MIDI / return track |
| Cmd/Ctrl-click, Shift-click | Add a clip to the selection (or take it out). Drag on empty lane space to box-select clips; drag to an edge of the arrangement and it scrolls, so the box can reach clips you can't see yet. Drag any of the selected clips to move them all together (up or down too, if each lands on a track of its own kind). |
| Cmd/Ctrl+A | Select all clips |
| Cmd/Ctrl+C, X, V | Copy / cut the selected clips; paste them at the start marker on the selected track (click an empty spot to put the marker there) |
| Cmd/Ctrl+D | Duplicate the selected clips |
| Right-click a track | **Export This Track...**: export just that track (or every selected track): a mix of only those tracks and/or a file per track |
| Cmd/Ctrl+J | Join the selected clips on each track into one clip (audio is rendered to a new file) |
| Cmd/Ctrl+E | Split the selected clips at the start marker |
| Delete | Delete the selected clips (or notes in the piano roll) |
| Cmd/Ctrl+Z, Shift+Z | Undo / redo: clips and notes, tracks, returns, groups, plug-ins, routing, sends, names, tempo, and fader, pan, send level and channel EQ moves |
| Cmd/Ctrl+K | Compare: Before, Now and a reference track, playing in step (1, 2, 3 switch; Space plays) |
| Cmd/Ctrl+Alt+Z | Undo History: every step, who made it (you or the AI assistant) and when; click one to go back to just before it |
| File > New from Template > Delete Template | Delete any template, built-in ones too (**Restore Built-in Templates** brings those back) |
| Cmd/Ctrl+scroll | Zoom. Shift+scroll scrolls sideways. Hold Alt while dragging to ignore the grid. |
| Piano roll | Double-click (and drag) to add a note, or B for Draw to add them with a click; double-click a note to delete it. Drag to move, Alt-drag to copy, drag either end to resize, Cmd/Ctrl to ignore the grid. ↑↓ transpose (Shift: an octave), ←→ nudge by the grid (Shift: shorter/longer), Cmd/Ctrl+C/X/V/D copy, cut, paste and duplicate notes, Cmd/Ctrl+E split, Cmd/Ctrl+J glue, Q quantize, Z zoom to fit, Alt+scroll for taller rows. Right-click for Legato, Reverse and Invert. See [MIDI and the piano roll](midi.md) |
